# Rishit Rajput — Static Portfolio

A simple static version of my personal portfolio, built using HTML and CSS.

This project is a lightweight frontend-only portfolio that showcases a little about me, my interests, and some of the projects I've worked on.

## ✦ What's Inside

- Personal introduction
- Computer Science & AI/ML background
- Project showcase
- About section
- Contact section
- Links to GitHub, LeetCode and other profiles

## Built With

- HTML5
- CSS3

No frameworks or JavaScript — just plain HTML and CSS.
